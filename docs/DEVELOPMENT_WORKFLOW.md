# Flujo de desarrollo

1. Mantener repositorio remoto y local sincronizados antes de crear una rama.
2. Investigar, analizar y definir opciones en Work Mode desde navegador; registrar decisiones duraderas en documentación versionada.
3. Implementar localmente mediante Codex CLI, con una rama y comandos reproducibles.
4. Revisar visualmente en navegador y obtener decisión del propietario para cambios de identidad o arte importantes.
5. Iterar; abrir PR y fusionar sólo después de validar. No requiere abrir VS Code u otro editor.

Para UI, las pruebas DOM no sustituyen la revisión del recorrido, contraste, tamaños ni movimiento en un navegador real.

Para propuestas de Claude Design y validación del catálogo local, seguir [DESIGN_CATALOG.md](design/DESIGN_CATALOG.md). La conversión y sincronización externa se verifican por separado.
