# Visual references — principles only

The owner reviewed Zenless Zone Zero character-profile screenshots (Base Stats / Skills / Equipment) and a character roster screenshot; the YouTube description cites a subsecond right-to-left triangular selection transition. These are **qualitative observations**, not frame-accurate extraction.

**Zenless Zone Zero:** character-dominant layouts, expressive anime poses, kinetic typography, asymmetry, bold black/white/color graphics, diagonal cuts, restrained continuous lettering motion, per-character accents, a distinct layout per information tab, and a single right-fixed SELECT arrow. Interpret squash-and-stretch, smear frames and exaggerated poses as animation principles; do not clone the implementation.

**Wuthering Waves:** sophisticated atmosphere, narrative framing, satisfying VFX for mission start, purchasing, claiming rewards and important milestones. Build a feedback hierarchy from quiet microconfirmation to high-impact rare events.

**Honkai: Star Rail:** clarity of character progress and unlock status; do NOT invent a Traces-style progression tree absent confirmed Vyrathen rules.

**Neverness to Everness:** world-integrated navigation as secondary inspiration; do not simply copy a mobile menu layout.

**Vyrathen-specific synthesis:** Neon Elegance (structure) + Cyberpunk Expression (personality) + Arcane Cyberpunk (VFX). Hybrid splash art/menu + sprite-based automatic combat, whose outcomes and rationale remain transparent. Third-party screenshots/video/assets stay OUTSIDE this repository; review rights before shipping art.
