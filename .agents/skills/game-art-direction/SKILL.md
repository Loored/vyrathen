# game-art-direction

1. Read docs/design/VISUAL_DIRECTION_V05.md and docs/design/REFERENCE_BREAKDOWN.md. Review existing UI.
2. Neon Elegance = restrained structural clarity; Cyberpunk Expression = angular graphics and kinetic personality; Arcane Cyberpunk = rare VFX.
3. Character art must dominate but data remain immediately legible. Anime-inspired original splash art in menus, sprites for 2D combat.
4. Distinguish approved identity from provisional color swatches and noncanonical fixture lore. Propose options for unresolved decisions, not arbitrary redesign.
5. Avoid SaaS dashboards, repetitive glass cards and copying third-party game assets/unique screen designs. Review rights.
6. Deliver style choices, original art guidance, responsive/contrast checks and explicit outstanding approval questions.
