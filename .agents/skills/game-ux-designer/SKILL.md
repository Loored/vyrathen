# game-ux-designer

1. Read docs/UI_UX_GUIDELINES.md, docs/design/CHARACTER_LAB_SPEC.md and docs/PRODUCT_VISION.md.
2. Define player intent, feedback states, information priority, keyboard/focus semantics, disabled/error/empty/loading states and consequences.
3. Keep character primary and base stats available without desktop scrolling; tabs can use different graphic arrangements.
4. Don't invent equipment slots, ability progression trees, currencies, gacha mechanics or arbitrary game rules: seek historical evidence and clearly label concepts.
5. Reduced-motion and accessible alternatives cannot hide any essential action/info. Validate 1366×768 first, then responsive.
6. Deliver wireframes, interaction state matrix, acceptance criteria and provenance of gameplay data.
